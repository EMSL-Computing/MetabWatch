# Files in data folder

1. `original_QC_list.xlsx`: This file was acquired from W. Kew April 2026
2. `corems_params`: This directory contains the CoreMS parameter files used for the QC analysis.
3. `qc_search_space`: This directory contains the CSV files that define the search space for the targeted search of standards. One is for HILIC chromatography and the other is for reversed-phase (RP) chromatography.
4. `raw_negative`: This directory contains the raw LCMS data files acquired in negative ionization mode for testing and development purposes.
5. `raw_positive`: This directory contains the raw LCMS data files acquired in positive ionization mode for testing and development purposes.
